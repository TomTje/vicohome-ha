# VicoHome for Home Assistant

**Custom integration for VicoHome CG1 cameras**

- 📹 Motion detection via cloud events
- 📸 Snapshot camera + event image entity
- 📊 Sensors: events, battery, signal, IP, firmware
- 🔔 Telegram notifications (photo + video)
- 🎛️ Buttons: snapshot, refresh, restart *(planned)*
- ⚙️ Runtime config via HA UI
- 🌍 English + German translations for all entities
- 📝 New `translations/en.json` and `translations/de.json`
- 🔧 All entity names use HA translation system (`translation_key`)
- 📨 Notification messages default to English
- 💾 Persistent serial cache (survives restarts)

**v1.3.0**

**Unofficial** – reverse-engineered cloud API. Tested with **CG1** model only.
